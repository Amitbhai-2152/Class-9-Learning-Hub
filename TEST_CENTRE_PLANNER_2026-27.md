# Class 9 Bihar Board Learning Hub — Test Centre Planner 2026–27

## Operating model

- Test Centre is **manually managed**. A test appears only when we deliberately add/build it.
- Regular examinations are planned on **alternate Sundays**.
- The Sunday between two examinations is a **revision / break Sunday** and does not generate an automatic test.
- This document is the master syllabus planner. Individual test question banks can be added later without changing the calendar structure.
- **First-pass syllabus coverage target:** complete the main syllabus by Test 08.
- **Tests 09–12:** structured revision, mixed practice, weak-area checking and BSEB-style mocks.
- **Final Exam:** 28 February 2027, complete syllabus.
- Reasoning is kept outside the main academic Sunday-test allocation for now.

## Manual publishing rule

A planner entry does **not** automatically generate a test. The workflow is:

1. Select the planned test entry.
2. Build and QA its question bank.
3. Connect the bank to the Test Centre entry.
4. Mark the entry as Published.
5. Keep the same test entry available in history after the examination.
